Use this checklist before you sign quotes or start demolition.

## 1) Scope clarity

- [ ] Room-by-room scope documented
- [ ] Must-haves vs optional upgrades separated
- [ ] Functional constraints captured (storage, workflow, accessibility)

## 2) Visual planning

- [ ] Before photos taken from multiple angles
- [ ] Style references saved and grouped
- [ ] Candidate design directions tested in Renosnap

## 3) Quote readiness

- [ ] 2–3 itemised quotes requested
- [ ] Inclusion/exclusion assumptions confirmed
- [ ] Timeline assumptions and milestone payments documented

## 4) Risk controls

- [ ] Contingency budget allocated
- [ ] Access/logistics constraints discussed
- [ ] Approvals/permits understood where relevant

## 5) Decision lock-in

- [ ] Fixtures/finishes selected before demolition where possible
- [ ] Long-lead items ordered early
- [ ] Single source of truth for changes agreed with trades
